# DataVisualization2418053
Analisis dan Visualisasi Data Students Performance
Proyek ini bertujuan untuk melakukan pembersihan dan visualisasi data nilai siswa menggunakan Python di Google Colab. Dataset yang digunakan adalah Students Performance in Exams dari Kaggle.

Tahapan Analisis
Membaca dan memeriksa dataset.
Melakukan pembersihan data (data cleansing).
Membuat visualisasi data menggunakan:
- Diagram batang
- Diagram garis
- Histogram
- Diagram sebar
- Diagram lingkaran
Menganalisis hasil visualisasi dan menarik kesimpulan.

Sumber Dataset
Kaggle — Students Performance in Exams
https://www.kaggle.com/datasets/spscientist/students-performance-in-exams/data
