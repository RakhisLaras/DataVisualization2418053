# DataVisualization
Analisis dan Visualisasi Data Students Performance
Proyek ini bertujuan untuk melakukan pembersihan dan visualisasi data nilai siswa menggunakan Python di Google Colab. Dataset yang digunakan adalah Students Performance in Exams dari Kaggle.
Analisis berfokus pada nilai matematika, membaca, dan menulis, serta beberapa karakteristik siswa yang tersedia dalam dataset.

Tujuan
- Memahami struktur dan karakteristik dataset.
- Melakukan pemeriksaan dan pembersihan data.
- Membandingkan rata-rata nilai siswa berdasarkan jenis kelamin.
- Menganalisis rata-rata nilai berdasarkan tingkat pendidikan orang tua.
- Mengetahui distribusi nilai matematika.
- Mengamati hubungan antara nilai matematika dan membaca.
- Menampilkan proporsi keikutsertaan siswa dalam kursus persiapan ujian.

Teknologi yang Digunakan :
- Python : bahasa pemrograman untuk analisis data.
- Pandas : membaca, mengolah, dan memeriksa dataset.
- NumPy : mendukung operasi numerik.
- Matplotlib : membuat visualisasi data.
- Google Colab : untuk menjalankan kode Python.

Tahapan Analisis
Membaca dan memeriksa dataset.
Melakukan pembersihan data (data cleansing).
Membuat visualisasi data menggunakan:
- Diagram Batang (Bar Chart) 
- Diagram Garis (Line Chart)
- Histogram
- Diagram Sebar (Scatter Plot)
- Diagram Lingkaran (Pie Chart)
Menganalisis hasil visualisasi dan menarik kesimpulan.

Sumber Dataset
Kaggle — Students Performance in Exams
https://www.kaggle.com/datasets/spscientist/students-performance-in-exams/data
